# 0.0.7a-dev.2.R5 — Nonblocking handoff tickets and real entity-state capture

Version: package `0.0.7a-dev.2.R5`; Node `0.0.6a.R19`; Manager API / gateway R19;
Minecraft 1.21.1 / NeoForge 21.1.250.

This is a **development increment toward 0.0.7a**, not final 7a.

**Changes:**
- Replace synchronous 25-chunk destination preload (radius 2) with bounded
  center-first region tickets, at most four new tickets per server tick.
  Check actual chunk readiness before signaling ready, hold tickets for a
  10-second post-ready grace, free them on expiry/shutdown/abort. Requests are
  independently keyed by handoff to avoid overlapping-ticket interference.
  Fail closed on missing dimensions/invalid coordinates or timeouts.
- Add `EntityContinuationCodec`, capturing full vanilla serialized NBT for the
  five certified native entity classes, with UUID/type/dimension/time bound
  and mandatory decode validation. The adapter is capture/readback **only**.
- Add three GameTests that exercise actual NBT capture, save/load roundtrip for
  cow health/age and item components, wrong identity/type/world and corruption.
- New portable preloader self-tests exercise queued ticket rate, readiness,
  idempotent duplicate commands, timeout, cleanup, overlap and shutdown.
- All previous R4 automatic display-only entity views, inventory/safety
  reference ledgers, manager controls and dataplane safety fences are retained.

**Explicitly NOT implemented:** live authority transfer, world/anchored inventory
reconciliation, entity promotion, remote pickups, modded generic entity
compatibility, remote Survival world edits, multiplayer V0 acceptance, or
verified hitch elimination. Joined-client evidence is still required. Existing
player data/worlds/config/secrets/journals are never part of the updater.

See `docs/HANDOFF_AND_ENTITY_STATE_R5_GUIDE.md`. Completion depends on actual
Windows/Linux CI and NeoForge GameTests, plus user tests on a disposable world.
