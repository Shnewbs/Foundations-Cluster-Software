# Foundations Cluster 0.0.6a.R19-HF14

Fixes Generated Tree Persistence stopping at the single hard-coded occupied fixture area.

- Searches seven bounded 16×24×16 volumes within the same spawn chunk, preserving occupied blocks and logging the selected coordinates.
- Rechecks that the selected volume is empty before generating the oak. If all candidates are occupied, fails with a specific explanation without placing or clearing a fixture.
- Uses the same selected volume for every 6,144-state hash comparison and cleanup.
- Retains blocks if their observed hash changed unexpectedly, including a failed transfer. Confirms fixture removal before reporting a successful test and releases temporary force-load tickets.
- Updates the Test Lab consent text and adds tests for occupied areas, fallback selection, intervening changes, failed cleanup and repeated runs.
- Ships the updated dashboard files in the checksum/backup/rollback updater alongside the existing HF12/HF13 fixes.

## Install

Stop Manager, gateway and workers, extract the updater separately, and run `APPLY_UPDATE.bat` against your existing HF11/HF12/HF13/HF14 installation. Restart and refresh the dashboard with **Ctrl+F5**. Worlds, credentials, configuration, Node R13 and the seamless-mode setting are preserved.

The original occupied-area message means the test did not reach persistence verification. This update does not turn a blocked fixture into a false pass or establish live-world persistence correctness.

## Replica editing limitation

Node R13's remote block prototype forwards Creative break/place requests. It explicitly cancels non-Creative edits on a replica. Survival support requires the v2.2 authority-side interaction and durable player transaction work (tools, drops, inventory and mod events); it is not implemented by this UI repair. If Creative edits fail too, that requires runtime route/authority diagnostics. No mutation guard was removed.

CI validates the real Test Lab functions with simulated API/console responses and the updater transactions. Live Minecraft acceptance is still required.
