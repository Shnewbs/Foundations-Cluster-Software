# 0.0.7a-dev.2.R6 — Direct cumulative upgrade repair

**Development release** for 1.21.1 NeoForge 21.1.250. This is not playable final 7a.

R5 updates were insufficiently cumulative for actual older source trees: just 25
application files, with Node and Manager binaries but not the full source/build
scripts. R6 packages the reviewed exact tracked application-source snapshot along
with the compiled R19 Manager/Node/gateway and dashboard. It preserves config,
worlds, workers, templates, credentials, runtime, logs and unrelated local files.

The updater prints the selected install root, the detected old package revision,
the installed R6 revision, and its rollback folder. It validates payload digests,
backs up every replaced application file and supports rollback after an interrupted
transaction. The installer does not run arbitrary source code from other versions.

CI includes direct upgrade from actual HF12 release components plus diverged legacy
application files, same-version reinstall, tampered packages and forced rollback.

**Limit:** updating source/build scripts does NOT imply verified game or data-schema
migration for every historical modpack. Never test first on your only world.
Cross-worker Survival, entity ownership transfer and transactional pickups remain
intentionally disabled until their separate live 7a acceptance gates pass.

Package: 0.0.7a-dev.2.R6. Manager/Node/Gateway: 0.0.6a.R19.
