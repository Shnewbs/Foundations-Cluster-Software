UPGRADE SAFETY
- Incremental updater only replaces Manager binary/version source, Desktop files,
  and WebUI files listed above.
- It does NOT overwrite config, runtime state, workers, logs, server-template,
  Velocity, worlds, player profiles, persistence journals, or credentials.
- A timestamped backup of every replaced file is created before apply.
