Scaling

Human-controlled worker capacity and autoscaling guardrails

Reading host memory budget…
Scaling ModeMANUAL
Scaling Recommendation
0.0.6a can automatically expand JVM capacity, then consolidate population and Region Authority back onto fewer workers when load falls. Scale-down can batch-drain excess JVMs so population and Region Authority consolidate onto the minimum safe worker set. The RAM budget is a hard guardrail. New workers use the locked cluster seed, and world identity checks seed + mod versions + datapacks + worldgen-relevant configs.
