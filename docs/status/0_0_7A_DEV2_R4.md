# 0.0.7a-dev.2.R4 — Certified Vanilla Entity Views and Recovery Models

**Experimental installer**, Node R18, Manager API/gateway R19, Minecraft 1.21.1 / NeoForge 21.1.250. Not completed 7a.

- Extend automatic server-authoritative UUID presentation from cow/item to **pig, sheep and chicken**, using their actual vanilla type and synchronized metadata packets. Explicit type/class and unsupported passenger/leash checks retained; no automatic modded compatibility claim.
- Add checksum-protected durable `EntityOwnershipLedger`: full stage image, source owner generation and epoch fence, Manager-side compare-and-set prototype, explicit old owner tombstone metadata, repeat/abort/restart and process-kill recovery. Local file lock is not a network lease; world worker storage adapters are not connected.
- Add checksum-protected durable `PickupTransferLedger`: propose, reservation, world commit, player grant, clear, precommit abort and duplicate suppression. Reject competing transfers for an unfinished item; no effect on actual player inventory or item entities.
- Extend Java 21 portable regressions, 3 deliberate JVM kills, 2 real NeoForge vanilla packet/species GameTests, exact-version packaging, Windows rollback test. The **specific results of Windows/Linux CI** must be checked before calling this candidate validated.

**Still disabled:** actual entity authority move, remote AI/interaction/pickup, generic modded support, off-layer Survival, joined-client V0 seamless proof and pause reduction. These prototypes are safety groundwork and not permission to enable the user-facing feature in an active world. See [acceptance gates](../ENTITY_TRANSFER_R4_GATES.md).
